# Installation

Installation will provide the Quality Guardian OpenCode agent globally.

Planned flow:

Repository
  ↓
install.sh
  ↓
~/.config/opencode/agents/quality-guardian.md
  ↓
OpenCode
  ↓
quality-guardian

The installer must be:

- idempotent
- safe to rerun
- explicit about installed files
- independent from a specific project
- compatible with the supported environment

The final installation procedure will be documented after the installer is implemented and tested.
